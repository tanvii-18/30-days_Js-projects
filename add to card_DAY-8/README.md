<h3>📦 Add to Cart Website</h3>

A simple and elegant shopping interface where users can explore products and add them to their cart seamlessly.
Built with HTML, CSS, and JavaScript, this project displays a range of products like clothes, books, cosmetics, and more with an interactive cart counter.

Features:

Product catalog with images and prices

"Add to Cart" button functionality

Live cart item count

Responsive and beginner-friendly code structure

Tech Stack:

HTML | CSS | JavaScript
